Cross-agent validation

DeepSeek (OpenCode) and Kimi each plan, agree on a plan, implement it, and agree on the code.

New run

A local git repo, or a GitHub URL (cloned to Documents\Default Project, or reused if it is already there).
With two branches the agents first judge them blind as Candidate X and Y: a branch both approve is the result; otherwise they agree on a base and a plan, and both implement it.

Agree: both write a plan and approve or reject each; a plan both approve is used. Build: both implement it from the same base. Judge: both approve or reject each result, blind; one both approve is merged into origin's default branch and pushed. Otherwise they agree on a base and a fix plan and build again; after 3 builds the result both would keep wins (a split: a coin flip).
