Cross-agent validation

DeepSeek (OpenCode) and Kimi build to a plan, then review both builds until one has no blocker both agree on.

New run

Leave every branch empty to start from a task. With branches, set 1 and set 2 are the two attempts to reconcile; an empty branch in a set means that repo's main.

Task: both plan and vote until both approve one plan, then both build it. Review: both list only blockers (real bugs, real departures from the plan) in both builds, blind, and vote on each other's; only blockers both agree on count. Then both plan the fixes on a base they choose, in line with every plan agreed before, vote until both approve one, and both build it. It repeats until a build has no agreed blocker, which is kept as branch cav/<run> in each repository. Nothing is pushed.
